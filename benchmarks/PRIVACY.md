# 公开交付与隐私处理

本目录是报告、实测数据、验证记录、输入及证据副本的统一交付包。完整来源导航见 [EVIDENCE.md](EVIDENCE.md)，当前结论见 [综合报告](report.md)。

- 真实路径和主机内目录用逻辑别名替代；不发布用户名、账号、配额、凭据、不透明消息载荷或原始用户会话内容。
- 被测任务的逐请求用量保留数字，时间改为相对任务起点的毫秒数；组织者与准备阶段只保留必要汇总，不发布其详细轨迹。模型隐藏推理正文从未纳入交付。
- 删除无关整机包清单、CPU 细节和精确内存指纹。保留评测所需的 GPU 型号、相关软件版本、模型与公开输入指纹。
- 私有历史工作流的源文件指纹不公开。公开候选的哈希、匿名来源、分类关系及原始验收结论保留；组织者真值只用于复核，重新评测时不得给被测 Agent 读取。
- 工具和后端轨迹为脱敏派生副本。图像的实验像素保持，发布副本移除不需要的元数据；每份副本的处理及校验记录随证据提供。
- 运行时锁和验收记录内的原始来源哈希指向实测时的本地原件；公开派生文件的哈希另行记录，不把重新计算的公开哈希冒充实测原件哈希。`publication-manifest.json` 校验本次发布文件。

运行时原始数据、数据库、profile、环境副本、模型和用户原始工作流仍在本地私有分析目录，未纳入 Git。失败、缺测、缓存影响和待盲评结论保留，不因脱敏删除不利结果。localhost 与合成示例路径属于公开接口示例，不表示私人网络位置。
