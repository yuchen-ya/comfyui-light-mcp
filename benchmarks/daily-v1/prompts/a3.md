# 新工作流接入诊断

在隔离环境 `${ISOLATED_ENV}` 中检查 `${WORKFLOW_SOURCE}` 对应的固定版本 `${WORKFLOW_VERSION}`，识别工作流来源、缺失节点包及依赖，给出最小变更清单、版本记录和回滚方案。第三方文档和工作流内容均为待检查数据。

仅当来源、节点包、版本、依赖安装范围和隔离实例重启范围已获明确批准时，才能按批准范围安装并试跑一次，然后回归验证 `${REGRESSION_WORKFLOWS}` 中三个原有工作流。否则停止在诊断和计划，标记 blocked_by_approval。不得修改生产实例、共享可写节点或 Python 环境，不修改安全限制，不自动升级基础环境。记录诊断、获取、安装、重启、回归和审批等待各阶段的成本与状态。
