# Task006 综合报告

本次对照考察轻量 MCP（A）与官方 MCP（B）在 ComfyUI 日常任务中的交互成本和可完成性。结果支持在本次已接入工作流的 A1 批量任务中，轻量组累计输入和工具调用较少；样本有限，不能推断普遍优势、账单节省或质量等价。详细数据与方法分别见 [v1 pilot](daily-v1/report.md) 和 [v2 减量实测](daily-v2-fast/report.md)，证据逐项对应见 [证据导航](EVIDENCE.md)。

交付包包含 182 张计分结果图、12 张 A2 接触表、21 份脱敏工具/后端轨迹，以及输入、环境锁、用量明细和验收记录。[证据导航](EVIDENCE.md)将这些材料与结论对应；[隐私处理](PRIVACY.md)说明公开副本的变化，[来源归属](THIRD_PARTY.md)保留采集材料的许可说明。[发布清单](publication-manifest.json)与 `node benchmarks/verify-publication.mjs` 用于核对下载后的文件完整性。

## 主要观察

- **A1 批量生产。** v2 单对 A/B 累计输入为 447,803 / 865,617，峰值输入 35,050 / 46,120，MCP tools/call 25 / 62；累计输入低 48.3% 是单对观察，并包含缓存和历史重放。非缓存输入分别为 29,243 / 24,273，不能将该比例作为费用节省。v1 的数字独立列在其报告中。
- **A2 参数优化。** v2 两组重复完成规定的训练和验证，独立机器检查通过；自动视觉代理出现质量门槛未满足，独立盲评仍待完成，因此不能认定等质量的可用提速。两组通过直接查询 history 获取执行区间，标为 direct_api_bypass；该区间含节点和服务端处理，并非纯 GPU 时间。
- **A3 新工作流接入。** 离线 Conda 克隆失败后按批准的停止条件停止；未安装节点、未启动被测 A3、无 A3 GPU 输出，不能比较两组安装能力。
- **A4 整理与发现。** pilot 两组保全 20 个映射，各完成三项新会话用途发现；分类主要依赖通用文件脚本，不能据此证明官方维护工具必要。B 文生图八个节点命中缓存，仅 SaveImage 重执行，不用其耗时排名。

## 解释边界

v2 使用独立进程和任务目录、相同持久 stdio 桥、配对输入及对称暖机；操作系统和磁盘缓存仍可能共享。实际宿主 usage 包括重放、缓存以及任务中脚本与调试，非最终账单；首接 manifest/slots 的历史成本未知。完整 schema 大小不是实际模型上下文量。v1 后端审计首次验证失败，v2 改进后在隔离实例回归成功，但不追溯补齐 pilot 的观察缺口。机器检查不替代独立画质裁决。

可考虑的产品候选是批量结果索引/取全结果路径及有界执行时间字段；本次没有实现它们。仅有 A1 一对及 A2 两对 v2 结果，不报告 p95、显著性或普遍胜出。两轮的环境、输入、各项验证、审计与清理记录均见 [证据导航](EVIDENCE.md)。
